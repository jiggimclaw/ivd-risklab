# IVD RiskLab

> **Educational and experimental project only — not for regulated, clinical, diagnostic, or production use.**

IVD RiskLab is a personal learning and portfolio project exploring **FMEA-based risk analysis concepts in the field of in-vitro diagnostics (IVD)**.

The project combines software development, Git/GitHub workflows, UI/UX design, data modelling, and structured risk-analysis concepts in a practical learning environment.

## Project Status

**Early development / learning project**

IVD RiskLab is being developed incrementally as a hands-on software engineering and GitHub learning project.

The initial focus is on modelling a structured FMEA workflow and understanding the relationships between:

- components and inputs,
- failure modes,
- causes and effects,
- hazards,
- sequences of events,
- hazardous situations,
- harms,
- initial risk,
- risk-control measures, and
- residual risk.

The methodological structure is inspired by established FMEA and medical-device risk-management concepts. Regulatory terminology is used for educational and contextual purposes only.

The project is intended to provide practical experience with:

- UI/UX design

## Development Approach

IVD RiskLab is developed incrementally using a GitHub-based workflow:

`Issue → Branch → Implementation → Commit → Pull Request → Review → Merge`

Each development step is intended to remain small, traceable, and understandable.

## Current Scope

The first development stage will focus on the core FMEA and risk-analysis model.

Planned capabilities include:

- structured FMEA records,
- cause-and-effect chains,
- hazard and harm modelling,
- configurable risk evaluation,
- risk-control measures,
- residual-risk evaluation,
- local data storage,
- import and export, and
- basic reporting.

The scope may evolve as the project progresses.
